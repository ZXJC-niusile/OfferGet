Legacy report resource / 历史报告资源

This file is a compatibility notice, not an executable report template or a candidate report.

此文件仅用于兼容历史资源路径，不是可执行的报告模板，也不是候选人报告。

The active default report is generated by core.jd_analyst.reporter.OfferStrategyReporter. Calling generate_report with no template, an empty template, or this bundled resource path selects that renderer. Editing this file does not change the generated default report.

默认报告由 core.jd_analyst.reporter.OfferStrategyReporter 生成。省略模板、传入空模板路径， 或传入此内置资源路径，均使用该渲染器；编辑此文件不会改变默认报告。

For a custom report, create a separate HTML file and pass its path to the --template option or generate_report(template_path=...). Only supported placeholders are replaced, and all inserted values are HTML-escaped. See docs/REPORT_TEMPLATES.md in the source repository.

自定义报告请另建 HTML 文件，并通过 --template 或 generate_report(template_path=...) 指定路径。仅支持文档列出的占位符，插入的值均经过 HTML 转义。详见源码中的 docs/REPORT_TEMPLATES.md。
