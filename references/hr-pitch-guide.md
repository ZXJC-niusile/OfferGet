# 大厂直聘触达与猎头推荐话术规范（HR Pitch Guide）

在当今国内一线互联网大厂与 AI 独角兽的招聘语境下，**简历只是交付物，如何将交付物高效触达用人决策者是决定转化率的另一半关键**。

无论是 Boss 直聘、猎聘、脉脉，还是通过猎头推荐与员工内推，HR 与业务 Leader 每天面临着上百份同质化的“模版轰炸”。本指南总结了大厂招聘场景下的实战触达心法：**Boss 直聘 80-150 字黄金三段式抗模板化开场白**、**猎头/内推专业 Executive Summary 推荐模板**，以及 **HR 10 秒初筛首屏 1/3 视觉动线法则**。

## 一、 国内大厂招聘触达语境与决策链路

在大厂招聘流程中，信息触达呈现出明显的**漏斗递进与阅读疲劳**特征：

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        国内大厂直聘决策筛选漏斗                         │
├────────────────────────────────────────────────────────────────────────┤
│ 1. 消息列表预览 (1秒)  ──> 仅看前 20 字与学历年限，决定是否点开聊天框    │
│ 2. 开场白沟通 (3~5秒)  ──> 80-150字三段式，评估是否匹配当前急缺业务痛点 │
│ 3. 简历首屏扫视 (10秒) ──> 首屏上 1/3 区域，锁定技术栈高频词与标杆成果  │
│ 4. 发起面试 / 约聊     ──> 约聊意向达成，进入技术专家一面               │
└────────────────────────────────────────────────────────────────────────┘
```

> **致命痛点**：
> 超过 90% 的求职者使用平台自带的系统招呼语：“*您好！我对贵司的这个职位非常感兴趣，这是我的简历，希望有机会进一步沟通！*”
> 这类套话在每天看 200+ 投递的 HR 眼中等于纯粹的白噪音，被系统算法和人工直接划过。

## 二、 Boss 直聘 80-150 字黄金三段式开场白（抗模板化）

### 2.1 结构设计原理

黄金三段式开场白严格控制在 **80 ~ 150 字** 之间，移动端屏幕无需滑动即可完整阅读：

```text
┌─────────────────────────────────────────────────────────────┐
│ 【第 1 段：身份与硬核标签锚定】 (20-30字)                   │
│ 格式：[学历背景] + [目标岗位/年限] + [最强 1 个排他性标签] │
├─────────────────────────────────────────────────────────────┤
│ 【第 2 段：核心战力与强契合证据】 (40-70字)                 │
│ 格式：直击 JD 核心痛点 + 采用什么技术 + 产生什么量化收益   │
├─────────────────────────────────────────────────────────────┤
│ 【第 3 段：低摩擦触达与行动呼吁】 (20-30字)                 │
│ 格式：专业谦逊 + 随时在线 + 附带简历并请求交换联系方式     │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 抗模板化三大心法
1. **动态插桩**：开场白第 2 段中，**必须出现对方 JD 中的 1-2 个具体技术名词**（如 `vLLM PagedAttention`、`GRPO 强化学习` 或 `千万级 QPS 容灾`），绝不群发！
2. **数字威慑**：用真实的工程参数与百分比说话，拒绝空泛的“擅长”、“精通”；
3. **消除压迫感**：给对方最简单的响应路径（如“附件已附上单页简历，方便随时审阅”）。

---

### 2.3 三大方向高分实战范例

#### 范例 1：大模型 / Agent 算法工程师方向（128字）
> 您好！我是**浙大硕士、3年大模型算法研发**，前某头部大模型实验室核心成员，开源项目贡献者。  
> 针对贵司 JD 重点关注的**长推理与延迟瓶颈**，我曾主导基于 GRPO 与 Short CoT 的对齐优化，在 GSM8K 上达 82.5% (+14.5pp)，线上端到端 P99 降低 40%。  
> 附件附有一页精简简历，随时期待与您沟通！

#### 范例 2：高并发后端与分布式系统架构师方向（132字）
> 您好！我是**985科班计算机硕、5年高并发架构经验**，前一线电商核心交易中台骨干。  
> 针对贵司要求的**千万级 DAU 订单高可用**，我曾负责核心对账与幂等扣减重构，基于 Redis 分布式锁与内存环形队列彻底解决高并发热点超卖，大促承载 12w QPS 零故障。  
> 附件附有详细技术作品与单页简历，期待进一步交流！

#### 范例 3：搜推算法与数据平台专家方向（135字）
> 您好！我是**4年推荐算法专家**，主导过亿级日活内容社区双塔召回与重排链路搭建。  
> 匹配贵司当前**冷启动与跨模态特征融合**诉求，我曾通过 LanguageBind 多模态特征对齐与难负样本挖掘，将新用户次日留存提升 3.2pp，长尾内容点击率相对提升 18.5%。  
> 已附上个人技术简历，目前状态随时可聊，期待您的回复！

## 三、 猎头推荐与员工内推话术模板 (Executive Summary)

当猎头向大厂业务 Leader / HRVP 递送候选人，或内部员工进行高阶内推时，必须摒弃流水账，采用咨询级 **Executive Summary**：

### 推荐报告标准模板

```markdown
【候选人推荐报告】 张晨 (Chen Zhang) - 资深大模型推理优化工程师

一、 候选人基本面画像 (Candidate Snapshot)
- 教育背景：985 浙江大学计算机硕士（2021届）
- 目标对标：阿里 P7 / 字节 2-2 / 腾讯 10 级
- 核心标签：知名大模型开源框架 Committer | 从0到1搭建生产级推理优化管道

二、 核心胜任力 3 点突破 (Top 3 Core Competencies)
1. 【底层推理加速】：深入精通 vLLM 与 CUDA 显存带宽调优，主导过百卡集群 Continuous Batching 与 Chunked-Prefill 落地，线上 P99 延迟降低 50.0%。
2. 【对齐与强化学习】：掌握 GRPO / DPO 策略网络迭代，曾优化数学推理准确率提升 14.5 个百分点，具备严谨的离线/在线评测 Benchmark 方法论。
3. 【工程威慑与交付】：具备极强的代码自研与白板推演能力，主导代码合并超过 20+ 个核心 PR，单测覆盖率 99.5%。

三、 商务与背调置信度 (Logistics & Due Diligence)
- 离职状态：在职看机会，1个月内到岗，诚意度极高
- 薪酬期望：现金 65-75W + 期权激励
- 背调置信度：高（直接提供前司技术总监与开源社区 Maintainer 联合背书联系方式）

四、 推荐总结
该候选人工程基本功扎实，不仅能看懂前沿 Paper，更能下沉到显存调度与 C++ 算子底层交付生产级收益，完美契合贵司下一代长文本推理中台攻坚阶段。强烈建议安排业务 Leader 一面！
```

## 四、 HR 10 秒初筛首屏 1/3 视觉法则

大厂 HR 无论是使用 PC 显示器还是打印纸质简历，其视线停留与扫视遵循著名的 **“F 型”与“倒金字塔”动线**。页面顶部 **首屏 1/3 区域** 决定了 80% 的初筛存留率。

```text
┌──────────────────────────────────────────────────────────────────┐
│                   A4 单页简历首屏 1/3 黄金布局                    │
├──────────────────────────────────────────────────────────────────┤
│ 1. 极简 Header (压缩在 2 行内)                                   │
│    姓名 | 手机 | 邮箱 | GitHub (链接) | 城市 | 985/211 核心学历  │
├──────────────────────────────────────────────────────────────────┤
│ 2. 高势能 Headline / 核心优势 (2~3 行)                          │
│    ★ 4年大模型推理架构专家，主导亿级参数服务上线                │
│    ★ 知名开源项目 Maintainer (1.2k+ Star)，核心提交合并 20+ PR   │
│    ★ 精通 vLLM 显存优化与 GRPO 强化学习，线上延迟实打实 -50%    │
├──────────────────────────────────────────────────────────────────┤
│ 3. 专业技能速查矩阵 (ATS 机筛匹配区)                             │
│    【算法/模型】GRPO、DPO、LoRA、GSM8K Benchmark、短CoT优化     │
│    【系统/引擎】vLLM、TensorRT-LLM、CUDA、Ray、Continuous Batch │
├──────────────────────────────────────────────────────────────────┤
│ 4. 第一核心经历前 2 行 (直接切入高价值项目)                       │
│    某独角兽科技 | 核心推理中台架构师 | 2022.06 - 至今            │
│    - 主导长上下文推理引擎性能重构，服务峰值支撑 5000+ QPS...      │
└──────────────────────────────────────────────────────────────────┘
```

### 首屏 1/3 落地操作规范：
1. **Header 瘦身**：严禁占用过多纵向高度（如大头贴占半幅、民族/政治面貌/家庭住址等冗余信息彻底删除）；
2. **Headline 施压**：必须在前 5 行内抛出最有威慑力的成果，形成“高手”预设；
3. **关键词密度匹配**：按分类排布行业标准技术词汇，保障 ATS 机器扫描 100% 提取命中；
4. **黄金锚点先发制人**：第一段工作经历的第一行必须是极具冲击力的 Mini-RFC 结论句。
