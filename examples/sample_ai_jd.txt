【团队与业务使命】
我们致力于打造面向下一代通用人工智能（AGI）的核心基座模型与自主智能体（Autonomous Agents）操作系统。团队拥有自建万卡 H800/H100 独占算力集群与海量高质量多模态语料库，核心成员由来自顶级科技公司科学家及顶尖高校博士领衔。在这里，你将直接攻坚千亿级别大模型在预训练扩展、强化学习推理与工业级 Agent 核心场景的落地下限与能力上限。

【岗位核心职责】
1. 负责百亿至千亿参数规模语言与多模态大模型的预训练（Pre-training）演进，探索下一代稀疏 MoE 架构、长上下文注意力变体（MLA/GQA）与 Scaling Law 前沿边界；
2. 负责 Post-training 对齐技术栈研发，主导 SFT、DPO、PPO 及 GRPO 等强化学习算法在数学逻辑、复杂代码生成与多步深度推理（System 2 Thinking）任务中的算法调优与工业落地；
3. 负责大规模分布式训练工程攻坚，结合 Megatron-LM 与 DeepSpeed 源码改造 3D/4D 并行（TP, PP, DP, SP, CP），治理千卡/万卡长时间连续训练中的 Loss Spike、梯度异常及 Straggler 慢卡秒级自动隔离与容错自愈；
4. 负责高性能推理服务化与量化落地，深度优化 vLLM / SGLang / TensorRT-LLM 引擎，推动 FP8 混合精度量化、投机采样（Speculative Decoding）与 Chunked Prefill 架构在大规模高并发场景的落地，持续降低单 Token 服务成本；
5. 负责下一代企业级 Agent 架构基础设施建设，基于 Model Context Protocol (MCP) 与 GraphRAG 打造具备自省纠错（Reflection）、长短期记忆与复杂 Tool Calling 的智能体集群；
6. 深入业务一线，与业务方保持紧密合作，推进前沿算法在核心产品场景的变现与落地，带领团队攻坚核心技术难题。
