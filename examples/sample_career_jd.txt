【岗位名称】AI 推理工程师
【所属部门】智能应用平台组
【工作地点】北京 / 远程协作

【岗位职责】
1. 负责大模型推理服务的部署、性能测试与稳定性优化；
2. 基于 PyTorch、vLLM 等工具优化批处理、调度和延迟表现；
3. 与算法和基础架构团队协作，分析线上问题并沉淀压测与复盘记录；
4. 参与检索问答或 Agent 原型的评测与迭代。

【任职要求】
1. 计算机相关专业本科及以上学历，3 年以上 Python 工程或算法经验；
2. 熟悉 PyTorch，了解 vLLM 或其他推理服务框架；
3. 能说明性能指标的 baseline、测试环境、统计周期和个人贡献；
4. 具备良好的问题定位、技术沟通和复盘能力。

【加分项】
1. 有 C++、CUDA 或 Triton 性能优化经验；
2. 有生产环境故障排查或 Agent 工具调用项目经验。
